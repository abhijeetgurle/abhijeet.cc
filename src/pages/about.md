Hi, I'm Abhijeet. I'm a software engineer at [Akto](https://www.akto.io), based in Bengaluru.

Before Akto, I was in Mumbai, working on the ML Platform team at Dream11, building systems that manage the lifecycle of machine-learning models at scale. Most of my work has been on the backend: APIs, data pipelines, and the infrastructure underneath them. I mostly write TypeScript, Node.js, and Python.

Outside work, I like understanding things by building them from scratch. That has included a remote code execution engine (like the ones behind LeetCode), a BitTorrent client in Node.js, and an interpreter for the BASIC language. More recently I've been building with LLMs: an autonomous trading bot that uses Claude, with code-enforced risk limits, and a weekly tech-reading digest that runs entirely on GitHub Actions with no servers.

I write here about what I build and what I learn along the way.

## Background

- B.E. from Pimpri Chinchwad College of Engineering, Pune (2015–2019). My final-year project was a tomato crop disease detection app built on a retrained InceptionV3 model.
- Google Cloud Certified Associate Cloud Engineer (2019).
